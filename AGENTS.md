\# Studafy Agent Instructions



Before making architecture or code changes:



1\. Query Graphify first:

&#x20;  `graphify query "<question>"`

2\. If the graph may be stale, run:

&#x20;  `graphify update .`

3\. Use Graphify results to identify relevant files before reading the codebase.

4\. Do not scan the whole repository unless Graphify is insufficient.

5\. Keep changes small, production-grade, and aligned with existing architecture.
